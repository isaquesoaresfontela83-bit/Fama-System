# Integrações selecionadas — Fama 15.5

A configuração das seis APIs fica em **Fama Control → Integrações**. Essa central também permite ativar ou pausar cada API, executar testes, consultar a atividade, enviar documentos, extrair texto e consultar dados do GitHub, IPinfo e Sentry. Não é necessário abrir o painel do backend para salvar as credenciais.

No Fama System, as quatro integrações operacionais (Drive, Resend, Sentry e OCR.space) continuam disponíveis conforme o perfil e as permissões. Drive, e-mail e OCR ficam em **Ações do documento** nos arquivos anexados. As configurações da empresa mostram apenas o status. GitHub e IPinfo são exclusivos do Control.

Veja [Central de integrações](CENTRAL_INTEGRACOES.md) para conexão inicial, testes, proteção das credenciais, limites e regras de compatibilidade. A autorização inicial de conta e a emissão de credenciais continuam sujeitas aos requisitos de cada provedor. Configuração salva, teste confirmado e operação realizada são estados diferentes.
