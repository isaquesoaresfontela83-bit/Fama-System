# Segurança — Fama System

Para relatar uma vulnerabilidade, procure o responsável pelo projeto em um canal privado já estabelecido. Inclua a revisão afetada, os passos para reproduzir e o impacto, usando dados fictícios.

Não coloque senhas, tokens, dados de clientes ou anexos com informações pessoais em issues, pull requests ou exemplos. Use os arquivos `.env.example` como inventário; as configurações reais pertencem ao ambiente de execução.

Se uma credencial privada for enviada ao Git, revogue ou rotacione a credencial no provedor. Apagar o arquivo no último commit não remove as versões anteriores.

As regras específicas da aplicação estão em [README.md](README.md) e [docs/REPOSITORY.md](docs/REPOSITORY.md).
