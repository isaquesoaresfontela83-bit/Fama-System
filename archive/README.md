# Arquivos históricos

`legacy/fama-system.site-deploy-original.tar.gz` veio do repositório original do Fama System. Foi preservado integralmente e separado dos códigos ativos porque é uma compilação histórica.

Para publicar as versões entregues, compile as aplicações em `apps/`. O manifesto de origem registra a mudança de caminho desse arquivo e o seu hash original.

[github-main-2026-09-10/](github-main-2026-09-10/) conserva dez arquivos da antiga `main` do GitHub que não possuem equivalente no snapshot atual, incluindo funções Edge antigas, scripts de publicação e arquivos de autenticação. São referências históricas, com origem e hashes registrados; não integram os comandos de desenvolvimento, build ou publicação das aplicações atuais.
